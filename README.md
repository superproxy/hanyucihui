# hanyucihui

汉语词汇。记录常见术语的中文说法，也收从中文出发的创意命名。

## 宗旨

这个仓库讨论中文里的术语和命名，方向是：

1. 常见术语中文化，整理用得上的中文说法。
2. 引导中文创意，让中文主导更多领域。
3. 以中文孕育、表达、传播文化与理念。

给外语概念找译名只是一部分。也鼓励从中文出发创造词汇、新概念、文化表达和思想理念，让中文成为原创的起点，而不只是外来概念的载体。

收录才开始。规范定名、已经通行的说法，和本项目的原创候选，分开写。候选不是公认译法，也不说明流行程度或出处。

## 和规范的关系

本项目尊重国家通用语言文字的规范表达，以及科学技术名词等领域已经公布的定名。查考入口和少量已核验的代表文件见 [references.md](references.md)。

词条里，规范或通行名称与原创候选分栏。法律、国务院公布的字表、推荐性国家标准、部门规范，效力并不相同，不能把参考资料里的文件都当成强制规定。

这里的中文候选只供讨论，不当作规范定名。
